# Hangman: Advanced Educational Game 📚🕹️

![Status](https://img.shields.io/badge/Status-Completed-brightgreen)

## About the Project ✨

This project implements the classic **Hangman Game**, reimagined as an **advanced educational tool** designed to enhance English language learning. Developed with a modern frontend stack, this version goes beyond a simple game to serve as an engaging activity for English students.

As an educator, I've personally used and tested this game in my classes, observing a **significant increase in student engagement and content retention**, often exposing them to new vocabulary. It also notably **boosted my classroom productivity**, allowing for more efficient use of lesson time. The game features **three difficulty levels**, making it adaptable for students of various proficiency levels.

Technically, the project leverages **React.js with Vite** for a dynamic frontend, and modern styling with **Tailwind CSS and PostCSS**. This demonstrates strong frontend development skills, a deep understanding of component-based architecture, and a keen focus on user experience in an educational context.

## ✨ Features

*   **Educational Focus:** Designed specifically as an engaging English learning activity for students.

*   **Three Difficulty Levels:** Adapts to various student proficiencies, offering easy, medium, and hard modes.

*   **Dynamic Word List:** Utilizes a curated list of English words (managed directly by the frontend JavaScript for this version) for diverse vocabulary exposure.

*   **Interactive Gameplay:** Classic Hangman mechanics with letter guessing and visual feedback.

*   **Visual Feedback:** The hangman figure progressively updates with each incorrect guess.

*   **On-Screen Keyboard:** Interactive keyboard for letter selection, with visual cues for guessed letters.

*   **Win/Loss Conditions:** Clear messages indicating game outcome.

*   **Start/Reset Functionality:** Buttons to begin a new game or reset the current one.

*   **Fully Responsive Design:** Layout that adapts seamlessly to desktops, tablets, and smartphones.

## 🚀 How to Run the Project (Locally)

To run this frontend project on your local machine, follow the steps below:

### Prerequisites

*   [Node.js](https://nodejs.org/) (which includes npm, necessary for Vite)

### 1. Clone the Repository
```bash
git clone https://github.com/lucaspalmasanches/Hangman.git
cd Hangman
````

### 2. Install Dependencies

1.  **Navigate to the frontend directory:**

    ```bash
    cd frontend # Adjust if your frontend folder has a different name (e.g., 'React', 'client', 'app')
    ```
    *   **NOTE:** If your project structure has `index.html`, `src`, `package.json` directly in the root `Hangman` folder, you can skip `cd frontend` and install dependencies directly from the root.

2.  **Install dependencies (using npm):**

    ```bash
    npm install
    ```

    ### 3. Start the Development Server
```bash
npm run dev
````

*   The frontend application should open in your browser, usually on `http://localhost:1000`.

Now you can interact with the Hangman game locally!
